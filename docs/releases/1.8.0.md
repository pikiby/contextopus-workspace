# 1.8.0 — Assignment revisions and repeatable reviews

Workspace now prevents a prepared change from starting after the assignment has
changed, and provides a resumable inventory for complete reviews.

## Changes since 1.7.0

- Clarifications carry a stable `request_id`; retries do not duplicate them.
- Proposals capture `expected_task_revision`. A changed assignment requires
  reconsidering and preparing the proposal again. Recovery of partial writes
  retains the original revision checks.
- Review cursors report delivered records and concurrent changes without claiming
  that an agent understood the content.
- Read and review responses expose direct incoming/outgoing Workspace YAML links.
- Context instruction binding prepares one reviewed change, preserving other rules.
- Procedures require checking relevant knowledge after accepted intermediate results.

## Update and compatibility

Requires Python 3.12+ and Core >=1.8,<2. Update Core first, then use
`contextopus modules update workspace --source /path/to/workspace` with the
extracted release folder. Preview with `--plan`; preserve the existing data root.
See [installation](../install.md).

Active cycles and temporary files remain available. Unstarted legacy proposals
without an assignment revision return `reprepare_required`; read the assignment,
reconsider the change and prepare the same proposal again before applying it.
Refresh the procedure after updating: clarification and proposal arguments changed.
No SQL schema migration is added.

## Verification and limits

Local checks covered operation bounds, assignment revisions, clarification retries,
review cursors, relation candidates and existing regressions. The broad regression
run was completed in bounded groups; nine optional/platform cases were skipped.
Installed-artifact and isolated existing-data update checks passed. This does not
establish native assistant compliance or new Windows/macOS acceptance.

Relation coverage is currently `workspace_yaml_links`, not body or cross-module
links. Full shared document/link work remains unfinished.
