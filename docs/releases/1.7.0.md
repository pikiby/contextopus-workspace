# 1.7.0 — Shared instructions and project documents

Format 6 places the project record in Context.md and references complete Core instruction documents. Workspace records are available through the common web Library. Procedures include operation declarations and skills use full names. Existing data requires the explicit reviewed upgrade path; opening a context does not silently migrate it.

## Installation and compatibility

Use the assets attached to this release and verify their checksums. Modules in this coordinated release require Core 1.7 or later, below 2. Keep persistent data outside source and plugin folders. Use explicit update/upgrade previews for existing roots; client setup does not silently upgrade existing modules.

## Verification and limits

The local full suite passed 732 tests and 64 subtests; 9 optional tests were skipped. The built ZIP passed isolated installation, disablement and restart checks. Upgrade from the published 1.5 module preserved source bytes and pending work before the explicit format migration; competing writes were blocked and reservations survived restart. The real 1.1 writer migration passed in CI.

Deterministic embedding tests validate retrieval contracts, not real-model ranking quality. Packaging is not proof that every native client version was exercised.
